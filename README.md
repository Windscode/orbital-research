个人航天仿真研究网站。整理建模方法、工程工具、公开任务资料，并记录 AerospaceSimUE 项目的架构、实现与验证范围。

- 网站：https://windscode.github.io/orbital-research/
- 仓库：https://github.com/Windscode/orbital-research

## v13 更新

研究区默认打开按问题组织的索引 `#/research`，集中显示 10 项可阅读或运行的研究，说明输入、计算内容和可下载文件。新的 NACA 0012 页面位于 `#/research?view=data&case=naca0012`：读取 NASA Langley 发布的 CFL3D / SA 压力与总力文件，可选择三个迎角、逐面元检查压力贡献、对比七档采样密度，并导出计算记录与面元 CSV。

原文件只给 x/c 和 Cp；y/c 按旧验证网格的公式重建并明确标成派生量。10° 全量压力积分得到 CLp≈1.090921、CDp≈0.006123，原作者总 CD≈0.012311。网页说明压力与剪切、后处理与 CFD 网格收敛的区别，并展示粗采样恰好接近总阻力的误导性反例。标准库 Python 使用上下表面分别积分，与网页闭合面元算法交叉核对；这不是新运行的 CFD。

重写四篇知识正文：四元数约定与相位误差、飞轮动量约束、电推进完整工作点、结构模态与局部响应。Apollo 11 档案保留任务报告原始英制表并提供平行轴项开关；Hubble 补 JIT/JIF 字段和单位，Cassini 补 ISS 原始/标定产品及坐标核的使用边界。构型修订限于 Hubble 八片刚性太阳板及 Cassini 相机、MAG 臂和 Huygens 比例；Apollo 的构型来源改用具体 Apollo 11 资料。

工具补 FUN3D、Fluent、OpenFOAM 的具体输入与后处理步骤，新增 TMR 条目和情报维护来源；修正三项受限工具的目录分类。个人项目增加共同安装参考系和独立温度场的实现说明，锚定既有提交，没有重跑 UE。范围与剩余缺口见 [本轮验证](research/verification-v13.json)、[知识复核](research/content-review-v13.json)、[任务复核](research/vehicle-review-v13.json) 和 [项目复核](research/project-review-v13.json)。

## v12 更新（历史）

研究区默认打开公开数据研究：`#/research?view=data`。MRO 案例冻结 2024-01-01 至 01-02 TDB、Mars 499 中心、ICRF、NONE、KM-S 的 289 个六维状态。网页以通用变量 f/g 解传播，独立 Python 采用轨道平面椭圆解；原始响应、CSV/JSON、常数文件和 SHA-256 清单一并保存。24 h 模型差约 1005.563096 km，不能将其称为星历误差或直接归因于单项摄动力。数据是导航星历，不是直接观测；未运行本地 SPICE。

验证：`npm test` 包含原始响应逐行比对、文件哈希、全部样本 Python 交叉校核、轨道守恒与可逆性、RK4 步长求精、QR 协方差/秩及 GCI 反例。另在浏览器检查手机、平板、桌面布局、交互与实际下载后复算。范围记录见 [本轮验证](research/verification-v12.json)。没有声称整个目录已经达到同等深度，也没有新增 UE 仿真或制造级模型验证。

## v9 更新（历史）

轨道实验室分为轨道观察、双脉冲变轨、J₂ 长期漂移和数值积分四个工作区。空间轨道、时间滑块、状态读数与地面轨迹来自同一状态计算；6 种类型预设不是实际卫星星历。NASA Blue Marble 的 4096×2048 纹理用于球面和全球地面轨迹图。变轨页面只提供圆轨道升轨；J₂ 页面只旋转轨道的平均方向，不是完整摄动传播。

来源库按用途、主题、地区、语言与核查情况组织，共 47 个入口：本轮 32 个已阅读、5 个索引核对、10 个访问受限。停更档案与待复核入口单独保留。关注清单仅保存在本机；资料包和新来源提案可导出，但没有自动采集或定时任务。

## 本地运行

需要 Node.js 22 和 npm。

~~~bash
npm ci
npm run dev
~~~

访问 http://127.0.0.1:5173/ 。Windows 可运行 Start-Orbital.cmd；按 Ctrl+C 停止服务。

~~~bash
npm test
npm run build
npm run check:bundle
npm run preview
~~~

构建产物位于 dist/；预览地址 http://127.0.0.1:4173/ 。Vite 使用相对 base，静态图片、字体、延迟模块、Worker 和 GLB 均支持 GitHub Pages 的项目子目录。页面路由使用 hash，无需服务器重写。

## 部署

main 分支每次推送后，GitHub Actions 依次安装锁定依赖、运行检查、构建、检查入口体积，并发布 dist/ 到 GitHub Pages。工作流位于 .github/workflows/pages.yml，Pages 来源设为 GitHub Actions。需要重新运行时，可使用 Actions 的手动触发入口。

Pages 只部署静态网站，没有服务器、账户或数据库。书签与研究笔记保存在当前浏览器；本地开发站与公开站属于不同来源，迁移记录时使用知识库中的导出与恢复功能。

## 资料与验证范围

资料以官方文档、机构档案、论文与项目仓库为主要来源。核查日不代表所有链接当前仍可访问；内容变更应保留构型、版本、日期和证据来源。

三维模型是外部构型与功能级内部结构示意，不能当作实测 CAD、制造图纸或完整质量账本。例如 ISS 选用 2011 年主要总装构型，Galileo 表达高增益天线未能正常展开的状态，SLIM 表达设计着陆姿态。没有混用这些任务的后续状态。导出的 GLB 坐标经过展示归一化，不代表实物米制尺寸；剖切开口不生成实体封盖，不能直接进行质量或有限元计算。逐型说明见构型记录。

AerospaceSimUE 页来自只读源码和历史记录审查。本次没有构建或运行 UE 仿真；记录明确区分源码已实现、已读测试代码、历史验证和后续研究。本站不分发 UE 项目的源代码与大型资产。路径仅用于相对 UE5 工作区定位证据，不是可访问的源码链接。

轨道观察与数值积分采用点质量二体引力，数值台使用有限精度开普勒参考解；另有圆轨道霍曼升轨、平面变化预算及一阶 J₂ 平均方向漂移示意。它们没有完整摄动力传播、阻力、第三体、有限推力或任务级误差预算。测试验证结构、接口、有限几何、误差行为和状态恢复，不能替代独立科学审查或真实任务验证。
