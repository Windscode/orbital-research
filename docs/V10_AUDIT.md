## 内容与来源范围

- 新知识与工具调查记录：`research/content-additions-v10.json`，32 个来源记录，其中 29 个正文可读、3 个访问受限。访问受限不写为已经验证全文。
- 六个专题引用 18 个唯一一手来源；资料组织与研究步骤由本站整理。专题不是已运行的实验报告。
- 来源库新增 NESC、NASA SmallSat State of the Art、CCSDS、JAXA DARTS。51 个入口共 36 个正文读取、5 个搜索索引核对、10 个访问受限。没有创建自动抓取或定时更新。
- DARTS 的 SLIM 数据表仍列为准备中；任务介绍可访问不等于导航数据已经下载。
- AerospaceSimUE 只读；网站没有上传 UE 源码、原始日志或大型 CAD。新案例的历史结果转述日期化台账，本轮未重读这些新结果的全部原始日志。
- 新专题复用六幅已署名的任务影像；项目增加四幅代码绘制的流程/几何示意。没有用生成图片伪装求解云图。

`npm test`、`npm run build`、`npm run check:bundle` 通过。

- 内容字段、来源 URL 格式、引用唯一性、所有前置边、图谱 DAG 与 16 条路径顺序。

- 轨道实验已有独立标量和几何基准、守恒量、地面轨迹接缝、转移预算、J₂ 平均漂移及积分阶数检查继续通过。

- 浏览器实际操作：九页 390px 手机宽度无横向溢出；1440px 专题与主导航；中等宽度图谱；模型层级切换、专题阅读返回、搜索“共因”、研究方案直达、图谱领域/缩放/键盘/空搜索、四种项目案例与 JSON 下载。
- 实际下载的专题包含三层模型、四步研究与关联资料；项目审查包含四个案例、六项验证矩阵及 `testsExecuted: false`。

## 保留的后续扩充方向

本轮没有为凑数量新增飞行器型号，56 型结构示意继续保留原构型来源与未知项。下一步有价值的研究包括：反作用轮微振动与指向谱、天线极化/方向图耦合、使用真实试验数据做模型修正、动态冷备和多阶段任务可靠性。它们需要具体数据或明确工况，不能只靠扩大目录替代证据。

较早审查文件是历史快照；当前能力以本轮案例与逐条证据为准。读者的笔记与关注仍只保存在浏览器本机。
